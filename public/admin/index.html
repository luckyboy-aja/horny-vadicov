Ak používate administráciu priamo na webe bez spusteného lokálneho servera, CMS môže zapisovať nové články, VZN a zmeny priamo do GitHub repozitára cez GitHub Personal Access Token.

Token je bezpečne uložený len vo Vašom prehliadači (v localStorage).
