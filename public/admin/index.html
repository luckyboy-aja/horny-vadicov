Konfigurácia publikovania priamo z webu na GitHub Pages

Priame online publikovanie cez GitHub API

Ak používate administráciu priamo na webe bez spusteného lokálneho servera, CMS môže zapisovať nové články a oznamy priamo do GitHub repozitára cez bezpečný GitHub Token. GitHub Actions následne web automaticky prebuilduje a zverejní.

Token je bezpečne uložený len vo Vašom prehliadači (v localStorage) a neposiela sa na žiadne cudzie servery.
